## Constraints and review focus

- Preserve pre-existing checkout changes and user design assets. No wholesale UI or backend replacement.
- Use a Node runtime meeting package.json's >=22.18 floor; do not change the machine's global runtime.
- Keep membership, section capability ceilings, OAuth delegation expiry/revocation and actor isolation authoritative.
- Keep unknown outcomes recoverable with the same command; refresh failures cannot negate committed changes.
- Test current permissions again when approving AI proposals or agent evidence.
- Canvas must work by keyboard/mobile with AI disabled. Optional AI uses the existing provider and feature flag.
- Local acceptance operates only on explicitly verified disposable resources, with exact fixture cleanup.
- Record actual evidence; leave any external activation gate open unless it is exercised successfully.
